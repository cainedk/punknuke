Broadcasting as NEON-NODE

An offline survival archive you can wear.

PunkNuke is a Raspberry Pi 5 on the back of a cyberpunk plate carrier. It runs its own Wi-Fi, pops up a portal on every phone that joins, and serves medicine, repair, tech and survival knowledge with no internet at all.

What happens when you connect

No app, no password, no mobile data. It works like hotel Wi-Fi, except the login page is the whole point.

  1. Scan the QR codeThe screen on the wearer's back shows a code that joins the NEON-NODE network.
  2. The portal pops upEvery address resolves to the box, so the phone opens the PunkNuke page by itself.
  3. Search the archiveWikipedia, medical references, repair guides and Q&A sites, all served from an SSD in the box.
  4. Take the tools with youThe toolkit runs on your own phone: Morse, ciphers, converters, radio frequencies.

Inside the node

The portal sorts everything into sections, named the way the character would.

//MED

MDWiki and field-medicine manuals: first aid, treatment, drugs.

//REPAIR

iFixit guides plus electronics, Arduino, Raspberry Pi and DIY Q&A.

//NETRUN

Linux, security and programming references, and freeCodeCamp.

//SURVIVE

Water, food, shelter, knots, outdoors and sustainability.

//ARCHIVE

Wikipedia, Wikivoyage, Wiktionary, Wikibooks and anything else added later.

//TOOLS

Morse with sound and screen flashing, cipher decoder, unit and antenna calculators, radio reference.

//LOLZ

An offline comic archive. Survivors need to laugh too.

Build your own

On a fresh Raspberry Pi OS Lite with the library drive mounted at /mnt/data. The README has every step.

# get the code
git clone https://github.com/cainedk/punknuke.git
cd punknuke

# set it up, in this order
sudo bash scripts/setup-portal.sh wlan0 NEON-NODE
sudo bash scripts/setup-redirect.sh wlan0
sudo bash scripts/install-web.sh
sudo bash scripts/setup-admin.sh
sudo bash scripts/setup-kiosk.sh    # optional back screen
sudo bash scripts/setup-comics.sh   # optional //LOLZ

# fill the library in the background
nohup bash scripts/download-content.sh > ~/download.log 2>&1 &

The hotspot is open and unencrypted by design. Treat it as a public prop, not a private network.
